---
title: Suffix Array
---

Suffix Array is an efficient data structure used in many text-based algorithms, such as the full-text index, the longest common substring algorithm, and the longest common prefix algorithm. It stores a sorted array of all the suffixes (substrings) of a given string, where each suffix is represented as an index into the string from which it was derived. By storing the Suffix Array, we can quickly identify patterns in the text, as each suffix is represented in a known order, so the comparisons can be done quickly.
