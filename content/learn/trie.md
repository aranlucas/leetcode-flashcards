Trie, also known as digital tree or prefix tree, is a type of search tree used to store a dynamic set of data. Trie tree is a kind of data structure that makes it possible to store words or phrases in a way that can facilitate a range of searches related to the elements stored in the tree. It is used to store a large amount of data to search words quickly than a normal BST. It is an extremely special tree data structure that uses strings for searching. It is used for efficient retrieval of data by providing an alphabetical order of characters with a key sorting feature.
