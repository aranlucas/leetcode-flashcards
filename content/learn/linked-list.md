A linked list is a data structure consisting of a group of nodes which together represent a sequence. Each node contains a piece of data (e.g. an integer, character, or string) and a reference, or link, to the next node in the sequence. By sequentially following links it is possible to traverse the entire list. Linked lists allow for efficient insertion and deletion of elements, without the need to reallocate memory and copy the entire structure. Linked lists are commonly used in computer programs to implement queues, stacks and other abstract data types.
