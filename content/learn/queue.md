Queue is a First-In-First-Out (FIFO) data structure. It is a linear data structure (like arrays) where the first item added is the first item to be removed. It is commonly used for storing items in a line for a system to be processed later. Queue operations include enqueue (adding an item onto the back/tail of the queue) and dequeue (removing an item from the front/head of the queue).
