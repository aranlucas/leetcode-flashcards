---
title: Binary Tree
---

A binary tree is a data structure consisting of nodes that specify relations between elements of the structure. The root, or the topmost node, of the tree is typically referred to as the parent node. All of the other nodes in the tree contain data and have at most two child nodes. The child nodes of any node are referred to as its left and right child. The left child contains data that is less than the data in the parent node, and the right child contains data that is greater than or equal to the data in the parent node.
