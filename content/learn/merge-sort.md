title: Merge Sort
questionCount: 10
---

Merge sort is an efficient, in-place, comparison-based sorting algorithm. It is a divide-and-conquer algorithm that works by recursively breaking down a list into sublists, until each sublist consists of a single element and merging those sublists in a manner that results in a sorted list. Merge sort is an unstable sorting algorithm, meaning that relatively small changes in the input can cause large changes in the output.
