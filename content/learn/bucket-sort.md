---
title: Bucket Sort
---

Bucket sort, also known as bin sort, is an algorithm that works by partitioning an array into a number of buckets. Each bucket is then sorted individually, either using a different sorting algorithm, or by recursively applying the bucket sorting algorithm. In the end, the elements of the buckets are concatenated to get the sorted list. Bucket sort is often used in combination with other sorting algorithms, such as quicksort, to achieve better performance.
