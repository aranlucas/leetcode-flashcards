---
title: Hash Table
---

A hash table is a type of data structure used to store key-value pairs. It uses a hash function to compute an index into an array of buckets or slots, from which the correct value can be found. Hash tables are used in a wide variety of applications, such as databases, caches, and public-key cryptography. They offer efficient lookup time, constant time insertion and deletion of elements and no need for resizing.
