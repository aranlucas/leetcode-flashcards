---
title: Heap (Priority Queue)
---

Heap (Priority Queue) is a type of data structure in which the smallest item is always located at the root of the structure. Heaps are typically implemented as binary trees, where each node holds a priority value and the root holds the smallest priority value. The structure allows for fast retrieval and removal of the smallest item, while also providing the ability to add new items quickly. Heaps are commonly used to implement priority queues, where the highest priority items are always processed first.
