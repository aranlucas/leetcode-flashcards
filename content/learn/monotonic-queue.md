title: Monotonic Queue
questionCount: 11
---

Monotonic queue is a data structure that stores and maintains the order of the values that have been added to it. It is often used for solving sliding window maximum and minimum problems and other algorithmic tasks. A monotonic queue has the following functions: enqueue, dequeue and get subtree max / min. These functions allow the user to add, remove, and find the largest/smallest element in a window of elements.
