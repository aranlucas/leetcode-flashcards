Prefix sum, also known as cummulative sum, is a technique used in programming where each item in a sequence is "summed" up with its preceding items. This can be useful for finding a range of elements in a sequence quickly or for speeding up algorithms. For example, a prefix sum array might look like this: [1, 3, 6, 10, 15, 21] The numbers in the array are the sums of the first five elements in the sequence, starting with the first element having a sum of 1.
