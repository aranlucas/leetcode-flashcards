Rejection sampling is a type of random sampling used in statistics. It is a method of randomly selecting elements from a larger population where individual elements are chosen based on an appropriate probability distribution. In this method, each member of the population is assigned a probability value and then a randomly generated value from a uniform distribution is compared with the probability value of each element. If the value falls within the range specified by the probability then the element is accepted and sampled, otherwise it is rejected and another randomly generated value is generated and compared with the probability value of the next element.
