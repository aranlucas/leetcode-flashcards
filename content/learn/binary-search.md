---
title: Binary Search
---

Binary search is an algorithm used to search an array or list for a given value by repeatedly dividing the list in half. It starts by comparing the middle element of the list with the search value and can determine whether the value is lower or higher than the middle element. If the value is lower, the algorithm limits its search to the lower half of the list; if the value is higher, the algorithm limits its search to the upper half. The binary search algorithm continues in this manner until the value is found or returns a not found result.
