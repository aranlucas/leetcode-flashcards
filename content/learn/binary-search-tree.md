---
title: Binary Search Tree
---

A binary search tree is a type of data structure that is made up of nodes which each contain a value and two branches (sometimes referred to as "children") that point to other nodes. When searching for a node with a given value in a binary search tree, you can use an efficient technique called "binary tree search" that starts at the root node and works its way through the branches to locate a node with the correct value. Binary search trees are a commonly used data structure for quickly searching and retrieving data in computer applications.
